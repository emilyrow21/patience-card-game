# Patience Card Game

A Java-based Patience card game developed as a university Computer Science project. 
The game combines a console-based menu with a JavaFX card display, 
allowing players to deal cards, manipulate piles and track their results.

## Features

- **Deck management:** Generate and shuffle a standard 52-card deck.
- **Card dealing:** Deal cards individually into piles and update the card display.
- **Pile manipulation:** Combine piles when their top cards match by rank or suit.
- **Automatic gameplay:** Execute individual moves or automate multiple moves.
- **Results tracking:** Save game results to a file and display the top 10 results.
- **Player customisation:** Set a username to associate with game results.
- **JavaFX visualisation:** Display card images in a separate window.
- **Object-oriented design:** Separate classes for cards, decks, piles and game logic.

## Technologies Used

## How to Play

The game uses a standard 52-card deck. Cards are dealt one at a time, 
with each card initially forming its own pile.

Piles can be combined when their top cards share either the same rank or the same suit.

The game supports the following actions:

1. Print the deck.
2. Shuffle the deck.
3. Deal a card.
4. Move the last pile onto the previous pile.
5. Move the last pile onto the pile two positions back.
6. Select two piles to combine.
7. Display the current piles.
8. Play one automatic move.
9. Play five automatic moves.
10. View the top 10 results.
11. Change the player username.
12. Quit the game.

When the deck is exhausted, the game records the player's username and 
the number of remaining piles. Results are sorted by pile count, with fewer remaining remaining 
piles appearing higher in the results. 

## Project Structure

The project is organised into the following main classes:

- **`Game.java`** — Runs the application, handles the console menu and updates the JavaFX card display.
- **`CardGame.java`** — Provides shared game functionality, including deck operations and result-file writing.
- **`PatienceGameLogic.java`** — Implements the gameplay rules, pile movements, automatic moves and results display.
- **`Card.java`** — Represents an individual playing card and checks whether two cards match.
- **`Deck.java`** — Creates, shuffles and deals the 52-card deck.
- **`Pile.java`** — Stores cards and handles pile combination operations.

### Additional Files and Resources

- **`cards/`** — Contains the card images used by the JavaFX display.
- **`cards.txt`** — An additional project file.
- **`results`** — Stores recorded game results when generated by the application.
- **`CardTable`** — JavaFX display support code provided with the project.
